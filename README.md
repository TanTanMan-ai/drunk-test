# 주량 테스트 🍻

술자리에서 1분 만에 재는 주량 테스트. 설치 없는 모바일 웹, 서버 없음.

## 실행

```bash
python3 -m http.server 8765
```

브라우저에서 http://localhost:8765 접속. 가속도 센서는 HTTPS 또는 localhost에서만 동작합니다.

## 배포

정적 파일뿐이라 Cloudflare Pages, Vercel, GitHub Pages 어디든 폴더째 올리면 됩니다. 빌드 단계 없음.

## 구조

| 파일 | 역할 |
|---|---|
| `index.html` | 진입점, 스크립트 로드 순서 |
| `style.css` | 다크 테마, 모바일 우선 레이아웃 |
| `bac.js` | 술 종류 정의, Widmark 공식으로 혈중알코올농도 추정 |
| `games.js` | 미니게임 5종 (초록만 탭!·따라가!·거꾸로!·버텨!·똑바로!) |
| `score.js` | 게임 결과 → 저하 지수 → 등가 BAC → 주량 계산, 등급표 |
| `share.js` | 1080×1920 결과 카드 생성, Web Share API |
| `app.js` | 화면 흐름(인트로 → 입력 → 게임 ×4 → 결과), 돌려쓰기 순위 |

## 흐름

1. 성인 확인 → 성별·몸무게·마신 양·경과 시간 입력
2. 게임 4개, 총 1분 안팎
   - 초록만 탭!: Go/No-Go, 선택반응 + 충동 억제
   - 따라가!: 움직이는 원 추적, 손눈 협응
   - 거꾸로!: 숫자 역순 기억 (3자리 시작, 5자리 성공 시 종료, 한 번 틀리면 즉시 종료)
   - 버텨!: 폰 수평 유지(가속도계). 센서 불가 시 똑바로!(직선 긋기)로 자동 전환
3. 결과: 등급, 추정 주량(소주 병), 추정 BAC, 법적 기준 초과 배지, 공유 카드

## 계산 방식

- **추정 BAC**: Widmark. `BAC(%) = 알코올 g / (r × 체중kg) × 0.1 − 0.015 × 시간`, r은 남 0.68 / 여 0.55
- **저하 지수**: 게임별 결과를 `score.js`의 `ANCHORS`(맨정신 기준, 많이 취함 기준) 사이에서 0~1로 정규화, `WEIGHTS`로 가중 합산
- **등가 BAC**: 저하 지수 × 0.12%. 평균인이 이 정도 저하를 보이려면 필요한 BAC
- **주량**: 내성 배율 = 추정 BAC ÷ 등가 BAC (0.3~3 클램프). 평균인이 0.08%에 닿는 병 수 × 배율. ±20% 범위로 표시
- 추정 BAC가 0.02% 미만이면 주량 대신 "맨정신 컨디션 점수"

## 튜닝 포인트

기준값은 임의 평균이며 `score.js` 상단 `ANCHORS`, `WEIGHTS`만 바꾸면 됩니다. 실제 사용 데이터가 쌓이면 여기만 조정하세요.

## 주의
